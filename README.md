# InfraMonitor
Sistema de monitoreo de infraestructura con frontend en Azure y backend en Ubuntu Server.

Sistema de monitoreo de infraestructura híbrida.

## Arquitectura

Frontend:
- Azure Static Web Apps

Backend:
- Ubuntu Server (Hyper-V)
- Node.js
- Express

Monitoreo:
- CPU
- RAM
- Disco

## Tecnologías

- HTML
- CSS
- JavaScript
- Node.js
- Express
- Azure
- Hyper-V
